# Neo-Launcher

Dark futuristic Android launcher prototype using Kotlin and Jetpack Compose.

## Rebuild 0.2.0
- Live digital clock and Indonesian date
- Live analog clock drawn in Compose
- Searchable installed-app library
- Dark navy and cyan interface
- PNG clock/date assets will be added under app/src/main/res/drawable-nodpi/

Build with Android SDK 36 and JDK 17, or run the GitHub Actions workflow. Verify on a real Android device before daily use.
