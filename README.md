## About

Neo Launcher is an Android home screen project exploring a simple, programming-inspired interface. It pairs a terminal-style visual design with the essentials: a live clock and a list of installed apps you can open directly.

> **Project status:** The `main` branch documents the v0.1 baseline. Newer experimental features may be available on development branches.

## Features

- **Terminal-style interface** with monospace typography.
- **Color accents** for a distinctive programming aesthetic.
- **Live clock** displayed on the launcher.
- **Installed app list** showing apps available to launch.
- **Quick app launch** by tapping an app name.
- **Android Home/Launcher intent** so the app can act as a home-screen launcher.
- **GitHub Actions APK build** workflow.

## Build

An Android APK build workflow is included in GitHub Actions.

1. Open the repository's [Actions tab](https://github.com/MazBayID/Neo-Launcher/actions).
2. Select the Android build workflow.
3. Open a completed run to review its status and download any available artifacts.

To build locally, open the Android project in Android Studio with a compatible Android SDK and use the Gradle wrapper provided by the repository.
